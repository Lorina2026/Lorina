# 《何以成人，青年何为》课堂互动页 · 部署说明

一次性做完下面 4 步，全班就能扫码实时互动了。全程免费，大约 15 分钟。

| 步骤 | 做什么 | 耗时 |
|---|---|---|
| 第一步 | 建 Supabase 数据库（跑一段 SQL） | 8 分钟 |
| 第二步 | 把 2 个密钥填进 `index.html` | 2 分钟 |
| 第三步 | 放入 4 张照片（可选，随时可补） | 1 分钟 |
| 第四步 | 上传到网站 | 3 分钟 |

## 第一步 · 建数据库（Supabase）

1. 打开 <https://supabase.com> → 右上角 **Start your project** → 用邮箱或 GitHub 注册登录（免费）。

2. 点 **New project**：
   - **Name**：`haigui`（随便填）
   - **Database Password**：随便设一个，记不记都行（网页用不到）
   - **Region**：选 **Southeast Asia (Singapore)** —— 国内访问最快，千万别选美国
   - 点 **Create new project**，等 1～2 分钟初始化完成

3. 左侧菜单点 **SQL Editor** → **New query**。

4. 打开本文件夹里的 `supabase-建表.sql`，**全部复制**粘贴进编辑框 → 点右下角 **Run**。

5. 看到 `Success. No rows returned`，并且下方结果区显示两张表、行数都是 0 —— 数据库就建好了。

> 这个脚本可以重复运行，不会重复建表也不会报错。表结构、字段、权限、实时推送全都写好了，你不需要再自己想字段。

## 第二步 · 把密钥填进网页

1. 回到 Supabase，左侧 **Project Settings**（齿轮图标）→ **API**。

2. 页面上能找到两样东西，分别复制：
   - **Project URL** —— 形如 `https://abcdefgh.supabase.co`
   - **Project API keys** 里的 **anon / public** —— 一长串 `eyJ...` 开头的字符

   > ⚠️ 只复制 **anon public** 那一条。下面还有一条 `service_role`，那是最高权限密钥，**绝对不要**填进网页，否则任何人查看网页源码就能拿到它。

3. 用记事本或 VS Code 打开 `index.html`，**翻到文件最底部**（在 `</body>` 往上一点的地方），找到这段带星号的注释：

```js
/* ★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★
   ★   配 置 区 —— 只 需 修 改 下 面 两 行                          ★
   ...
   ★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★★ */
const SUPABASE_URL      = '';   // ← 在这里粘贴 Project URL
const SUPABASE_ANON_KEY = '';   // ← 在这里粘贴 anon public key
/* ★★★★★★★★★★★ 配置区结束，以下内容都不需要改动 ★★★★★★★★★★★ */
```

把两个引号里分别粘上刚才复制的内容：

```js
const SUPABASE_URL      = 'https://abcdefgh.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIs...';
```

保存。

> **怎么看有没有填对？** 双击 `index.html` 在浏览器里打开，滚到"你认为哪张照片封神？"那块：
> - 顶部显示 **`实时同步中 · 当前 1 台设备在线`** → 成功 ✅
> - 显示 **`未配置 Supabase · 本地演示模式`** → 没填对，检查引号有没有漏、有没有多空格

## 第三步 · 放入照片（可以先不放）

在 `haigui` 文件夹里新建一个 `photos` 文件夹，把 4 张照片放进去，**命名为 `1.jpg`、`2.jpg`、`3.jpg`、`4.jpg`**。

```
haigui/
├─ index.html
├─ supabase-建表.sql
├─ README-部署说明.md
└─ photos/
   ├─ 1.jpg   → 显示为「图一」
   ├─ 2.jpg   → 显示为「图二」
   ├─ 3.jpg   → 显示为「图三」
   └─ 4.jpg   → 显示为「图四」
```

放进去就自动生效，**不需要改任何代码**。

没有照片时，页面会显示唯美的黄昏渐变占位图（标着"图一"到"图四"），不会破图。照片可以随时补，补完刷新即可。

> 建议照片宽度压到 1600px 以内（每张 300KB 左右），网页打开更快。手机拍的原图直接放会有 3～5MB，加载会慢。

## 课堂当天 · 操作清单

**上课前 5 分钟：**
1. 电脑浏览器打开 `https://lorina2026.github.io/Lorina/haigui/`，投屏，按 F11 全屏
2. 手机也打开同一个网址，确认手机上能看到"实时同步中 · 当前 2 台设备在线"
3. 滚到最下面，**点一下二维码把它全屏放大**，让全班先扫码进页面

**讲解过程中：**

| 讲到 | 做什么 |
|---|---|
| 板块三 · 幻灯片 | 什么都不用做，4 秒自动切换；鼠标悬停会暂停，方便你展开讲 |
| 板块四 · 投票 | 让同学点「投票」，投屏上的票数和百分比会**立刻**跟着变 |

**临场小技巧：**
- 投票可以现场造气氛："现在图三是领先的，还有没有同学要翻盘？" 同学改投即可，票会跟着走（同一台手机只算一票，刷不了票）

```sql
  from public.messages order by created_at desc;
```

## 常见问题

**Q：手机上投票了，投屏没反应？**
A：看投屏页面顶部的状态胶囊。如果写着 `实时连接中断 · 已开启定时同步`，说明网络断了 —— 页面每 20 秒会自动补一次数据，等一会儿也会更新出来。教室网络不稳时这是正常的。

**Q：同学说"提交失败"？**
A：多半是校园网波动。页面已经做了 20 秒兜底同步，让他重新点一次提交即可。

**Q：免费额度够用吗？**
A：远远够。Supabase 免费版每月 500MB 数据库 + 200 个实时连接，一个班几十人用掉的是零头。而且**不会自动扣费** —— 免费版额度用完就是停止服务，不会产生账单。

**Q：网页会过期吗？**
A：Supabase 免费项目如果连续 7 天完全没有访问会被暂停（不是删除），登录后台点一下就能恢复。上课前一周记得打开看一眼。

**Q：字体为什么没显示成行楷？**
A：页面优先用**华文行楷**（随 Office 安装），一般装了 Office 的 Windows 电脑都有。如果这台电脑没有，会自动回落到**霞鹜文楷 → 楷体**，依然好看。想让正文字体也变成行楷，把 `index.html` 里 `--font-body` 那一行改成和 `--font-display` 一样即可（但正文用行楷，投影时后排同学读起来会吃力，不推荐）。

**Q：想改文案怎么办？**
A：`index.html` 里直接搜那句话就能找到，都是纯中文，改完保存上传即可。所有正文都集中在 `<main>` 标签里面。

## 附 · 换网址后怎么重新生成二维码

页面第九部分的二维码是**提前生成好内嵌进去的**（这样打开不依赖任何外部服务，最稳）。如果网址变了，重新生成一下：

1. 装一次二维码工具（只需一次）：
   ```
   pip install segno
   ```

2. 把下面存成 `make_qr.py`，和 `index.html` 放同一个文件夹：

```python
import re, pathlib, segno

TARGET = "https://你的新网址/"                     # ← 改这里
HTML   = pathlib.Path("index.html")

qr  = segno.make(TARGET, error='m')
svg = re.sub(r'\s+', ' ', qr.svg_inline(
        scale=1, border=3, dark='#34312D', light=None, omitsize=True)).strip()

html = HTML.read_text(encoding='utf-8')
html = html.replace(re.search(r"qrBox\.innerHTML = '(.*?)';", html, re.S).group(1), svg)
HTML.write_text(html, encoding='utf-8')
print('二维码已更新 →', TARGET)
```

3. 在该文件夹里运行 `python make_qr.py`，二维码就换好了。

> 也可以直接用任何在线二维码生成器，但记得在页面里把 `TARGET` 那一行的网址也同步改掉，否则页面会一直提示"地址不一致"。
